# SequenceGuider (`sequenceguider`)

탱고 연습 영상(파일 또는 유튜브 링크)과 **시퀀스 순서**를 주면, 영상을 피구라별 구간으로 나누고 각 피구라에서
**주의할 점**과 **자동 자세 체크 결과**를 정리한 학습 가이드(HTML)를 만들어 줍니다.

> 예: `살리다, 오초 아뜨라스 x3, 푸에라 데 에헤`
> → 3번 푸에라 데 에헤 구간: "상체가 빠지지 않게 — 머리부터 지지발까지 한 선", "골반이 뒤로 가야 합니다"
> 그리고 실제 영상에서 골반이 앞으로 밀려 나온 순간을 찾아 캡처와 함께 보여줌

## 빠른 시작

```bash
uv sync
uv run sequenceguider analyze 연습영상.mp4 -s "살리다, 오초 아뜨라스 x3, 뿌에라 에헤"
# → 연습영상_sequenceguider/index.html 을 브라우저로 열기
```

- 첫 실행 시 MediaPipe 포즈 모델(~9MB)을 `~/.cache/sequenceguider/`에 받습니다. GPU 없이 CPU로 동작합니다
- 영상 없이 주의점만 보고 싶으면: `uv run sequenceguider guide "살리다, 오초 아뜨라스, 푸에라 데 에헤"`
- 알아듣는 피구라 이름 목록: `uv run sequenceguider figures`

### 유튜브 링크로 분석하기

```bash
uv run sequenceguider preview "https://youtu.be/XXXXXXXXXXX"      # 링크에서 읽은 시퀀스 미리 보기 (영상 다운로드 안 함)
uv run sequenceguider analyze "https://youtu.be/XXXXXXXXXXX"      # 챕터/설명란/자막에서 순서를 읽어 바로 분석
uv run sequenceguider analyze "https://youtu.be/XXXXXXXXXXX" -s "살리다, 오초 아뜨라스 x3"   # 순서 직접 지정
```

- 탱고 수업 영상은 **챕터**나 **설명란 타임스탬프**("0:45 오초 아뜨라스")에 순서가 적혀 있는 경우가 많습니다.
  이걸 피구라 이름과 맞춰 **순서와 각 피구라의 시작·끝 시간**을 자동으로 채웁니다. 스텝 수로 나누는 것보다 훨씬 정확합니다
- 인트로·Q&A처럼 피구라가 아닌 챕터는 건너뛰고, 그 구간은 앞 피구라에 섞이지 않습니다
- 챕터도 설명란 타임스탬프도 없으면 **자막**에서 읽습니다. 선생님이 "이제 오초 아뜨라스 해 볼게요"라고 말한 시점을
  그 피구라의 시작으로 잡습니다 (유튜브 AI 요약도 이 자막으로 만들어집니다)
  - 직접 올린 자막을 먼저 쓰고, 없으면 **원어 자동 자막**을 씁니다. 기계 번역 자막은 피구라 이름이 망가져서 쓰지 않습니다
  - "살리다에서처럼…"처럼 다른 피구라를 잠깐 언급한 것은 새 구간으로 치지 않습니다
  - 말한 시점 기준이라 실제 동작보다 조금 이를 수 있고, 챕터보다 덜 정확합니다. `preview`로 먼저 확인하세요
  - 음악만 나오는 시연 영상이나 자막이 없는 영상에서는 읽을 게 없습니다
- **유튜브 AI 요약을 붙여넣어도 됩니다.** 유튜브에서 영상 요약을 받아 복사한 뒤 `--summary`로 주세요 (아래 참고)
- 다 안 되면 `-s`로 순서를 알려주세요. 읽은 순서가 일부 틀렸으면 출력된 `-s "..."` 문자열을 복사해 고쳐 쓰면 됩니다
- 영상은 `youtube_<영상ID>_sequenceguider/source/`에 받아 두고 다시 실행하면 재사용합니다 (분석에 충분한 720p 이하, 소리 없이)
- **본인 영상이나 허락받은 영상만, 개인 학습용으로 사용하세요.** 유튜브 약관은 허용된 경우 외의 다운로드를
  금지합니다. 받은 영상과 결과물을 다시 배포하지 마세요
- 공연 영상(카메라 이동, 컷 전환, 밀착 홀드)보다 **고정 카메라 수업·시연 영상**이 훨씬 잘 분석됩니다

### 요약글에서 순서 읽기 (`--summary`)

유튜브 AI 요약처럼 순서가 문장으로 적힌 글을 그대로 넣으면 피구라 이름과 순서를 뽑아냅니다. 파일 영상에도 됩니다.

```bash
uv run sequenceguider preview --summary 요약.txt                         # 뽑은 순서 확인 (-s 문자열 출력)
uv run sequenceguider preview --summary -                                # 붙여넣고 Ctrl-D (Windows: Ctrl-Z 후 Enter)
uv run sequenceguider analyze "https://youtu.be/XXXXXXXXXXX" --summary 요약.txt
uv run sequenceguider analyze 연습영상.mp4 --summary "살리다로 시작해 오초 아뜨라스를 세 번, 마지막은 볼레오"
```

- 값은 파일 경로, 글 자체, `-`(붙여넣기) 중 아무거나 됩니다
- 이름이 나온 순서대로 읽고, 같은 피구라를 이어서 설명한 문장들은 하나로 칩니다
- `x3`, `3회`, `세 번`처럼 이름 바로 뒤에 붙은 횟수는 반복 수로 씁니다 ("두 번째 시도"는 횟수가 아님)
- 줄에 `1:05` 같은 시간이 있으면 그 줄에서 처음 나온 피구라의 시작 시간(`@1:05`)으로 씁니다
- "오초 아뜨라스는 살리다처럼…"처럼 문장 중간에 비교로 나온 이름은 건너뛰고, 끝에 "요약: A → B → C"로 전체 순서를
  다시 적은 부분은 두 번 세지 않습니다
- `-s`와 같이 쓸 수는 없습니다. 뽑힌 결과가 틀리면 출력된 `-s "..."`를 고쳐 쓰세요

### 긴 레슨 영상 → 자막·번역·핵심 노트 (`notes`)

1~2시간짜리 개인 레슨처럼 **설명이 대부분인 영상**은 동작 분석보다 "강사가 뭐라고 했나"가 중요합니다.
`notes`는 말을 받아 적고, 한국어로 옮기고, 복습할 핵심만 시간과 함께 뽑아 줍니다.

```bash
uv sync --extra notes                                   # 처음 한 번: 음성 인식(faster-whisper) + Claude API 패키지
export ANTHROPIC_API_KEY=sk-ant-...                      # 번역·핵심 정리에 필요 (받아쓰기만은 없어도 됨)
uv run sequenceguider notes "0915 개인레슨.mp4"            # 파일
uv run sequenceguider notes "https://youtu.be/XXXXXXXXXXX" # 유튜브 링크 (소리만 받습니다)
uv run sequenceguider notes 레슨.mp4 --role follower       # 팔로워 관점으로 정리
```

1. **받아쓰기** — 내 컴퓨터에서 Whisper(`--whisper turbo`, 첫 실행 시 모델 ~1.6GB 다운로드)로 말을 시간과 함께 받아 적습니다.
   언어는 자동 감지(`--language es`로 지정 가능). GPU가 있으면 쓰고, 없으면 CPU로 돕니다 —
   CPU에서는 영상 길이만큼 이상 걸릴 수 있으니 빨리 보고 싶으면 `--whisper small`.
   10분 단위로 저장하므로 중간에 끊겨도 다시 실행하면 이어서 합니다
2. **번역** — 줄마다 한국어로 (Claude). 탱고 용어는 한국 커뮤니티 표기(오초 아뜨라스, 사까다...)로. 레슨이 한국어면 건너뜁니다
3. **핵심 정리** — 전체 자막을 읽고 요약, **핵심 포인트**(시간·교정/원리/테크닉/음악성 등 종류·리더/팔로워·근거가 된 원문),
   **레슨 흐름**(구간별 요약과 다룬 피구라), **연습 체크리스트**, **용어 풀이**를 만듭니다. 개인 레슨이라 *나에게 준 교정*을 특히 챙깁니다

결과는 `analyze`와 같은 `<영상이름>_sequenceguider/` 폴더에 들어가서, 한 영상에 둘 다 돌리면 웹 레슨 화면에서 **노트 / 동작 분석**을 오갈 수 있습니다.

| 파일 | 내용 |
| --- | --- |
| `notes.json` | 웹 화면이 보여 주는 노트 전체 |
| `notes.md` | 같은 노트를 글로 (메모 앱·메신저에 붙여 넣기 좋게) |
| `transcript.json` | 받아쓴 자막 + 번역 (시작·끝 시간) |
| `transcript.srt`, `transcript.ko.srt` | 원문/한국어 자막 파일. 아무 영상 플레이어에서나 같이 열면 됩니다 |

- API 키 없이 돌리면 받아쓰기와 원문 자막까지만 만들고, 키를 넣고 같은 명령을 다시 실행하면 받아쓴 것은 재사용해 나머지를 채웁니다
- 정리만 다시 하고 싶으면 `--again` (자막·번역은 재사용). 모델은 `--model`로 바꿀 수 있습니다
- 2시간 레슨 기준 자막은 수만 단어라 번역·정리에 API 비용이 듭니다 (Claude Opus 기준 보통 1~3달러 안팎, 길이와 말의 양에 따라 다름)
- 영상 파일은 복사하지 않고 원래 위치를 가리킵니다. 파일을 옮기면 웹에서 재생이 안 되니 그때는 다시 실행하세요
- 기계 받아쓰기라 고유명사·음악 구간에 오류가 있을 수 있습니다. 핵심 포인트마다 근거 원문과 시간을 붙여 두었으니 눌러서 확인하세요

### 웹 화면으로 배우고 기록하기

```bash
uv run sequenceguider serve                  # 현재 폴더를 홈으로, 브라우저가 열립니다 (http://127.0.0.1:8765)
uv run sequenceguider serve --home ~/tango   # 분석 결과와 기록을 둘 폴더 지정
```

- **배우기**: 홈 폴더의 분석 결과(`<이름>_sequenceguider/`)가 레슨 카드로 보입니다. 카드마다 체크리스트 진도와 마지막 연습 날짜.
  **＋ 새 영상 분석**에 유튜브 링크(또는 영상 파일 경로 + 시퀀스)를 넣으면 웹에서 바로 분석을 돌립니다
- **레슨 화면**: 리포트를 그대로 보면서 연습 체크리스트를 체크하고, **연습 시작** 타이머나 **기록 남기기**로 연습 일지를 남깁니다
- **노트 화면** (`notes`를 돌린 레슨): 영상 옆에 **핵심 / 흐름 / 자막 / 연습·용어** 탭. 시간을 누르면 그 장면부터 재생되고,
  자막 탭은 재생 위치를 따라가며 원문+번역을 보여 주고 검색됩니다. 영상에는 한국어 자막이 함께 나옵니다.
  유튜브 링크로 만든 노트는 유튜브 플레이어로 재생합니다. **＋ 새 영상 분석**에서 "레슨 노트"를 골라 웹에서 바로 만들 수도 있습니다
- **기록**: 최근 7일 연습 시간, 연속 연습 일수, 날짜별 연습 달력, 피구라별 진도(여러 영상에 걸쳐 합산), 연습 일지. JSON으로 내보낼 수 있습니다
- 기록은 홈 폴더의 `records.db`(SQLite) 한 파일에 저장됩니다. 체크 항목은 피구라 기준이라 같은 피구라가 나오는 다른 영상에서도 이어집니다
- 기본으로 이 컴퓨터(127.0.0.1)에서만 열립니다. 휴대폰에서 열려면 `--host 0.0.0.0` (같은 네트워크의 누구나 열 수 있으니 집에서만)

### 옵션

| 옵션 | 설명 |
| --- | --- |
| `-s, --sequence` | 피구라 순서. 쉼표/`→`/줄바꿈으로 구분 |
| `--summary` | 유튜브 AI 요약 등 순서가 적힌 글 (파일 경로, 글, `-`) |
| `--view side\|front` | 카메라 위치. **측면(side) 권장** — 앞뒤 기울기·골반 위치·무릎은 측면에서만 보입니다 |
| `--role all\|leader\|follower` | 누구 관점의 주의점을 보여줄지 |
| `--person largest\|left\|right` | 여러 명이 보이면 누구를 볼지 (커플 영상은 `left`/`right`) |
| `--model lite\|full\|heavy` | 포즈 모델 크기 (정확도 ↔ 속도) |
| `--no-overlay` | 스켈레톤·자막 영상 생성 생략 (빠름) |
| `--library my.yaml` | 직접 고친 피구라 지식 베이스 사용 |

### 시퀀스 쓰는 법

```
살리다, 오초 아뜨라스 x3, 푸에라 데 에헤 @1:23, 볼레오
```

- **`x3`** — 같은 피구라 반복 (오초 세 번)
- **`@1:23`** — 그 피구라의 시작 시간 고정. 자동 분할이 어긋났을 때 이걸로 바로잡습니다
- 표기는 유연합니다: `뿌에라 에헤` = `푸에라데에헤` = `Fuera de eje`. 틀리면 비슷한 이름을 제안해요

## 결과물 (`<영상>_sequenceguider/`)

| 파일 | 내용 |
| --- | --- |
| `index.html` | 학습 가이드. 영상 + 피구라 타임라인(누르면 그 구간만 재생) 아래 두 탭:<br>**배우기** — 피구라별 핵심 한 줄, 주의점 2개(+더 보기), 흔한 실수, 연습 체크리스트(체크가 브라우저에 저장됨), 인쇄용 한 장 요약<br>**점검** — 배우는 순서 요약 + 피구라별 카드(주의점, 자동 체크, 문제 순간 캡처). 내 연습 영상을 분석했을 때 봅니다 |
| `overlay.mp4` | 스켈레톤, 현재 피구라 이름, 주의점/경고 자막을 입힌 영상 |
| `result.json` | 구간·체크 결과 원자료 |
| `pose_*.npz` | 포즈 캐시 — 시퀀스만 바꿔 다시 돌리면 포즈 추출을 건너뜁니다 |

## 어떻게 동작하나

1. **포즈 추출** — MediaPipe Pose(33점, 발뒤꿈치·발끝 포함)로 프레임마다 관절 위치
2. **스텝 감지** — 양발 각각의 이동 속도(상체 길이/초 단위)로 "발이 움직였다 멈춤" = 체중이동 1회를 찾습니다. 제자리 피벗은 스텝으로 세지 않습니다
3. **구간 나누기** — 피구라마다 보통 스텝 수(`figures.yaml`의 `steps`)가 있어서, 감지한 스텝을 그 비율로 나눠 가집니다. `@시간`이 있으면 그 지점에서 끊어 따로 나눕니다. 감지 스텝 수가 기대와 많이 다르면 "분할 확인 권장"으로 표시
4. **자세 체크** — 피구라별로 정해진 체크를 그 구간에서 평가합니다 (구간의 90% 기준, 튀는 한 프레임은 무시)

| 체크 | 무엇을 보나 |
| --- | --- |
| 몸 한 선 (허리 꺾임) | 어깨–골반–지지발이 일직선인가 |
| 골반 위치 | 지지발–어깨 선에서 골반이 앞으로 밀렸나(+) / 뒤로 빠졌나(−). 몸 전체 기울기와 무관해서 오프액시스 피구라에도 쓸 수 있음 |
| 상체 전후 기울기 | 골반→어깨 선의 앞뒤 기울기 |
| 축 수직성 | 지지발→몸통 중심 선이 수직인가 |
| 지지 무릎 각도 | 잠김(180°) / 과굴곡 |
| 머리 위치 | 귀가 어깨보다 앞으로 나왔나 |
| 발 모으기 | 구간 중 두 발을 한 번이라도 모았나 |

## 피구라 지식 베이스 고치기

주의점·기준값·별칭은 전부 [`src/sequenceguider/data/figures.yaml`](src/sequenceguider/data/figures.yaml)에 있습니다.
코드 수정 없이 이 파일만 고치면 됩니다. 현재 17개 피구라(까미나따, 살리다 크루사다, 크루사다,
오초 아델란떼/아뜨라스, 히로, 사까다, 볼레오, 빠라다, 빠사다, 바리다, 깔레시따, 간초, 볼까다,
꼴가다, 푸에라 데 에헤, 레보떼)가 들어 있습니다.

```yaml
fuera_de_eje:
  name_ko: 푸에라 데 에헤
  steps: 2
  key_point: "골반은 뒤, 머리부터 지지발까지 한 선"   # 배우기 탭의 핵심 한 줄
  prerequisites: [volcada, colgada]                 # 먼저 할 줄 알면 좋은 피구라
  cautions:                                         # 적힌 순서 = 우선순위 (앞 2개만 펼쳐 보임)
    - {role: all, text: "골반이 뒤로 가야 합니다 — 골반이 앞으로 밀려 나오면 축이 무너집니다."}
    - {role: all, text: "...", mistake: true}      # "흔한 실수"로 따로 보임
  drills:                                           # 연습 체크리스트
    - {role: all, text: "벽 옆에서 몸을 한 선으로 기울였다 돌아오기 10회"}
  checks:
    - {id: pelvis_offset, min: null, max: 0.03, message_high: "골반이 앞으로 밀려 나왔어요 — ..."}
```

`min`/`max`는 숫자로 덮어쓰고, `null`이면 그 방향 기준을 없앱니다.

## 한계 (꼭 읽어 주세요)

- **피구라를 자동으로 알아보지는 않습니다.** 순서는 사람이 알려줘야 합니다. 탱고 피구라별로 라벨이 붙은
  학습 데이터가 없기 때문입니다. 대신 이 도구로 만든 `result.json`(+ `@시간`으로 고친 구간)이 쌓이면
  그대로 라벨 데이터가 되어, 나중에 자동 인식 모델을 학습시키는 재료가 됩니다
- **주의점·기준값은 일반적인 탱고 교수법을 정리한 초안**입니다. 강사 검토를 거쳐 다듬어야 합니다
- 자동 체크는 **카메라 한 대의 2D 근사**입니다. 몸이 카메라와 비스듬하면 각도가 실제보다 작게 나옵니다.
  카메라는 **측면, 골반 높이, 수평**으로 두고 전신이 나오게 찍는 게 가장 정확합니다
- 스텝 감지는 발이 잘 보여야 합니다. 발이 가려지거나 화면 밖이면 분할이 부정확해집니다 → `@시간`으로 보정
- 한 사람 기준입니다. 커플 영상은 `--person left/right`로 한 명을 고르되, 두 사람이 겹치거나 교차하면 다른 사람으로 넘어갈 수 있습니다

## 개발

```bash
uv sync
uv run pytest -q     # 합성 스켈레톤 기반 테스트 (모델·영상 불필요)
```
